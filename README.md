# NCAA D1 Baseball Elo — 2026

Elo ratings, tournament simulations, and an interactive site for the 2026 NCAA D1
baseball tournament. Fits a `k=29, hfa=40, regress=0.07` Elo over 52,000+ games
from 2021–2026, simulates the 64-team bracket 20,000 times, and renders the
results as a static GitHub-Pages-deployable site.

**Live site:** *(enable GitHub Pages in repo settings → source: `main` branch, `/site` folder)*

---

## Site

`site/` is a self-contained static app: vanilla JS + [D3 v7](https://d3js.org/)
(CDN), no build step. Seven pages:

| Page | URL | What it shows |
|---|---|---|
| Leaderboard | `index.html` | Sortable, searchable table of all 311 D1 teams with current Elo, conference, 2026 record, championship %, CWS % |
| Team detail | `team.html?slug=<slug>` | D3 Elo trajectory line chart in team color, hover any dot or schedule row for opponent / score / pre-post Elo / Δ. Multi-year toggle (2021–2026 + All). |
| 2026 Bracket | `bracket.html` | All 16 regionals × 4 teams with 4-stage odds bars (regional / CWS / finals / champion) |
| What-If | `whatif.html` | Pin regional winners → re-runs 5k client-side sims, shows Δ vs baseline odds |
| Compare | `compare.html` | Search-driven team pickers, two-team Elo overlay + head-to-head win prob |
| Conferences | `conference.html` | Average end-of-season Elo per conference 2021–2026, toggleable |
| Upsets | `extras.html` | First-round Elo-vs-seeding disagreements, biggest 2025→2026 gainers and falloffs, model calibration plot |

Branding: black background, Driveline orange (#FFA300) accents, **Gotham Office**
font (embedded). NCAA Baseball logo as favicon.

## Pipeline

```
Warren Nolan + cached 2021–25  →  Elo fit + 20k sims  →  JSON exports  →  static site
```

| File | Role |
|---|---|
| `elo_rating_2026.ipynb` | Python notebook: load 2021–26 schedules, fit Elo from scratch, run 2026 sim, retrocast 2025 with MOV / recency variants for comparison |
| `scrape_warrennolan_2026.py` | Polite scraper for `warrennolan.com/baseball/2026/schedule/<slug>` (3–5s delay, resumable, abort on 403/429) |
| `wn_to_ncaa_name_map.py` | 86-entry reconciliation from Warren Nolan names → canonical stats.ncaa.org names so 2026 data joins the cached 2021–25 set |
| `export_site_data.py` | Builds every JSON the site needs in `site/data/` |

**Input data (committed):**

- `d1_sched_raw.csv` — cached 2021–2025 schedules (94k rows). Originally scraped from `stats.ncaa.org` via the 2025 R model. **Cannot be re-scraped now** — stats.ncaa.org has been Akamai-blocked since mid-2026.
- `d1_sched_2026_wn_raw.csv` — fresh 2026 scrape from Warren Nolan (16k rows).
- `d1_sched_2126_combined.csv` — joined 2021–2026 dataset (110k rows).
- `wn_teams_2026.csv` — 308 D1 team list with Warren Nolan URL slugs.
- `wn_2026_raw/` — per-team raw scrape cache (resumable, 1 file per team).

**Output data (committed; regenerated by `export_site_data.py`):**

- `final_elo_ratings_2026_py.csv`, `champ_probs_2026_py.csv`, `cws_probs_2026_py.csv`, `retrocast_2025_comparison.csv`
- `site/data/teams.json`, `bracket.json`, `odds.json`, `season_change.json`, `conference_elo.json`, `calibration.json`, `upsets.json`, `meta.json`
- `site/data/elo_history/<slug>.json` — per-team Elo timeline (311 files, ~18 MB total)

## Reproducing

```bash
# Optional — re-scrape Warren Nolan (~20 min). Skip if d1_sched_2026_wn_raw.csv is fresh.
python3 scrape_warrennolan_2026.py

# Refit Elo + run sims + retrocast
jupyter nbconvert --to notebook --execute elo_rating_2026.ipynb --inplace

# Regenerate every JSON the site needs
python3 export_site_data.py
```

Python dependencies: `pandas`, `numpy`, `scikit-learn`, `requests`, `beautifulsoup4`.
Notebook also uses `jupyter`.

## Model

Baseline Elo, identical math to the 2025 R model that lives on the
[`2025_model`](https://github.com/SamEhrlich/NCAA_bid_predictions/tree/2025_model)
branch — ported to Python without the `elo` R package dependency:

- Expected win prob: `E_A = 1 / (1 + 10 ^ ((R_B − R_A) / 400))`
- HFA `h=40` added to home rating (skipped on neutral-site games)
- Update: `R_team ← R_team + k * (actual − expected)`, `k = 29`
- Yearly regression toward the team's starting Elo by `r = 0.07`

Same number on the cached 2021–25 set:

| metric | Python | R | delta |
|---|---|---|---|
| games fit | 43,244 | 43,246 | −2 (date parse edge case) |
| MSE | 0.2149 | 0.2153 | −0.0004 |
| AUC | 0.6975 | 0.6957 | +0.0018 |

**Retrocast (2025):** fit Elo on 2021–25 (cuts off at Selection Sunday 2025), sim
the 2025 bracket with three variants (baseline, MOV-weighted, recency-weighted),
score against actual 2025 outcomes (LSU champion, Coastal Carolina runner-up):

| variant | avg CWS-prob of actual 8 CWS teams | LSU champ rank | Brier (CWS) |
|---|---|---|---|
| **baseline** | **21.4%** | **5** | **0.0216** |
| MOV-weighted | 20.6% | 6 | 0.0229 |
| recency (60d) | 17.5% | 27 | 0.0216 |

Verdict: baseline wins. No weighting applied to 2026.
