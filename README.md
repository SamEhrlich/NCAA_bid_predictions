# 2026 NCAA D1 Baseball Elo

### → [**Live Site**](https://samehrlich.github.io/NCAA_bid_predictions/)

Elo ratings, tournament simulations, and an interactive bracket explorer for the
2026 NCAA D1 baseball tournament.

- Leaderboard, team trajectories, 2026 bracket odds, what-if explorer, conference
  trends, upset radar
- Hover any game to see opponent / score / pre-post Elo
- 20,000 bracket simulations with multi-stage probabilities (regional → CWS →
  finals → championship)
